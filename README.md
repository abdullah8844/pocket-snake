# Pocket Snake — تجربة تثبيت لعبة آيفون من ويندوز

لعبة SwiftUI صغيرة، بدون إنترنت أو إعلانات أو مكتبات خارجية. تحتاج iOS 15 أو أحدث. التحكم بالأسهم أو السحب، مع حفظ أفضل نتيجة وإيقاف الحركة عند مغادرة التطبيق.

## حالة المشروع

هذه ملفات المصدر وإعداد البناء، وليست ملف IPA جاهزًا. لم يُنفّذ بناء iOS أو اختبار على جهاز آيفون في بيئة ويندوز. نجاح GitHub Actions هو التحقق التالي، ثم تجربة الجهاز الفعلية.

## بناء IPA باستخدام GitHub

1. أنشئ مستودعًا جديدًا باسم `pocket-snake`، واختر Public إذا أردت استخدام مشغلات GitHub القياسية مجانًا. لا تضع فيه كلمات مرور أو بيانات حساب Apple.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع تضمين `.github/workflows/build.yml`.
3. افتح تبويب Actions ثم `Build iPhone IPA` ثم `Run workflow`. قد يبدأ البناء تلقائيًا عند رفع الملفات إلى main.
4. بعد نجاح التشغيل، نزّل `PocketSnake-IPA` من Artifacts أسفل صفحة التشغيل، وفك ضغطه للحصول على `PocketSnake-unsigned.ipa`.

إذا رفعت الملفات عبر واجهة الموقع ولم يظهر مجلد `.github`، استخدم GitHub Desktop لإضافة محتويات المجلد كاملة ثم Commit وPush. لا ترفع ZIP وحده؛ يجب فك ضغط ملفات المشروع أولًا.

## التثبيت بالكيبل من ويندوز

1. نزّل Sideloadly من https://sideloadly.io/ واتبع متطلبات iTunes وiCloud المذكورة هناك لويندوز.
2. وصّل الآيفون بالكيبل، وافتح قفله، ووافق على الوثوق بالكمبيوتر.
3. افتح Sideloadly واختر الآيفون، ثم اسحب ملف IPA إليه وأدخل حساب Apple داخل البرنامج فقط.
4. اضغط Start وأكمل التحقق من حساب Apple إذا طلبه البرنامج.
5. إذا طُلب الوثوق بالمطوّر: الإعدادات > عام > VPN وإدارة الجهاز > حساب المطوّر > وثوق.
6. على إصدارات iOS التي تتطلب ذلك، فعّل وضع المطوّر من الإعدادات > الخصوصية والأمان > وضع المطوّر، ثم أكمل إعادة التشغيل والتأكيد.
7. افتح Pocket Snake وجرّب اللعب، الإيقاف والمتابعة، حفظ الرقم القياسي، والخروج والعودة.

التوقيع المجاني يحتاج التجديد خلال 7 أيام. لا تحذف التطبيق بغرض التجديد؛ أعد توقيع النسخة بنفس حساب Apple ومعرّف التطبيق للحفاظ على البيانات قدر الإمكان.

## البناء على ماك مباشرة

مع تثبيت Xcode واختيار أدواته: `bash build.sh`.
الناتج في `build/PocketSnake-unsigned.ipa` غير موقّع، ويحتاج التوقيع قبل التشغيل.
